# User Faces for Welcome Modal

This folder contains portrait images that appear in the rotating carousel on the welcome modal.

## Image Requirements

- **File names**: `face-1.jpg` through `face-12.jpg`
- **Format**: JPG (recommended) or PNG
- **Dimensions**: Square images work best (recommended: 400x400px or larger)
- **Subject**: Diverse portraits representing users from around the world
- **Count**: 12 total images

## Current Status

Currently using placeholder images. Replace these with actual user portraits.

## Adding Images

1. Save 12 portrait images in this folder
2. Name them sequentially: `face-1.jpg`, `face-2.jpg`, etc.
3. The carousel will automatically rotate through them every 2.5 seconds

## Image Tips

- Use high-quality, well-lit portraits
- Ensure diversity in representation
- Square crop works best for circular display
- File size: Keep under 500KB each for optimal loading
